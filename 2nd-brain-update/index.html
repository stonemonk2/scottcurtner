2nd Brain Update: Fix for the “URL Is Wrong” Connector Error

Scott Curtner November 11, 2026 Windows installs

If you set up a 2nd Brain from my install guide and Claude now says your connector’s URL (its web address) is wrong, or that the server isn’t responding, your URL is fine. The problem was a bug in the server code the guide installed. When Claude checks a connector it sends several requests at once, and the old code could only answer the first one. I fixed it on November 10, 2026.

The fix replaces that one piece of server code in your own Supabase account. Your saved memories, your access key, your connector URL and your settings stay exactly as they are. It takes about 10 minutes on the Windows computer you used for setup.

You don’t need to be technical. Copy the prompt below, paste it into a new Claude chat, and Claude walks you through each step one at a time, waiting for you between steps. It never asks for your passwords or keys... and if you paste one by accident, it tells you to stop.

Who needs this: anyone who installed before November 10, 2026, and anyone whose connector shows one of those two errors. New installs already include the fix.

The prompt

Paste into a new Claude chat 
You are my patient guide for a one-time update to my Open Brain "2nd Brain" (a personal memory system I installed from Scott Curtner's setup guide at scottcurtner.com). I am not technical. Treat me as a complete beginner.

WHY: My 2nd Brain connector in Claude may show "URL is wrong" or "server isn't responding" even though my URL is correct. The cause is a bug in the server code that was installed on my Supabase account. Scott published a fixed file. I need to download it and redeploy it. My saved memories, access key, URL and connector settings do not change. Only the server code is replaced.

HOW TO GUIDE ME:
- Give me ONE step at a time. Wait for me to tell you the result before giving the next step.
- For every step, tell me in one plain sentence what it does, exactly what to type or click, and what success looks like.
- When I need to run a command, give it as a single line in a copyable block, and tell me which program to type it into. All commands run in Windows PowerShell on my own PC. To open it: click Start, type PowerShell, press Enter. I do not need "Run as administrator".
- If I get an error, ask me to paste only the error text. Explain what it means in plain words, then give me the fix.
- NEVER ask me for passwords, my access key, my Supabase secret key, my OpenRouter key, or my connector URL (it contains my access key). If I paste one by accident, tell me to stop, and explain that the key should be replaced using Steps 5 and 6.7 of my setup guide.
- You cannot run commands for me. I run them and report back.

THE STEPS:

Step 1. Find my install folder. This is the folder I created in Step 6.1 of my setup guide (often named my-2ndbrain inside a folder called open-brain). Have me try this command to look inside it:
  Get-ChildItem $HOME/open-brain
If that fails, have me search my PC with this command (it can take a minute):
  Get-ChildItem -Path $HOME -Recurse -Directory -Filter open-brain-mcp -ErrorAction SilentlyContinue
The result shows a path ending in supabase, then functions, then open-brain-mcp. My install folder is the folder that CONTAINS the supabase folder. Have me go into it with the cd command, using forward slashes and quotes if the path has spaces, for example:
  cd "C:/Users/MyName/open-brain/my-2ndbrain"

Step 2. Find my Project Ref (my project's short ID code in Supabase). Have me run:
  supabase projects list
If it says I am not logged in, have me run supabase login, which opens a web browser where I approve the login, and then repeat the list command. Help me find the row named open-brain and copy its REFERENCE ID (a string of about 20 letters). Remember it for Step 5.

Step 3. Download the updated server file:
  Invoke-WebRequest -Uri https://raw.githubusercontent.com/stonemonk2/OB1/main/server/index.ts -OutFile supabase/functions/open-brain-mcp/index.ts

Step 4. Check that I got the new version. This command should print one line containing v1.2.1:
  Select-String -Path supabase/functions/open-brain-mcp/index.ts -Pattern "v1.2.1"
If it prints nothing, STOP. Tell me the update has not been published yet, and that I should ask Scott Curtner (scottcurtner.com) before going further. Do not continue to Step 5.

Step 5. Redeploy the server using my Project Ref from Step 2. The --no-verify-jwt part is required (it switches off JSON Web Token checking so Claude can connect), so never leave it out:
  supabase functions deploy open-brain-mcp --no-verify-jwt --project-ref MY_PROJECT_REF
Success looks like a line starting with: Deployed Functions on project. If I see a 403 error, have me run supabase login and repeat this step.

Step 6. Reconnect the connector in Claude. Have me open Claude, then Settings, then Connectors, and find my 2nd Brain connector. If it shows an error, have me remove it and add it again as a custom connector. For the URL, have me copy the connection URL from cell 6.13 of my setup guide and paste it straight into the connector form, NOT into this chat. Choose "No sign-in", add no request headers, and leave Advanced alone. Screen labels may differ a little, so ask me what I see if something does not match.

Step 7. Test. Have me start a brand new chat with the 2nd Brain connector switched on and ask: "Search my 2nd Brain for my name." If it answers without errors, we are done. If the connector still shows an error, have me remove it, wait one minute, and add it again.

Do not use a custom header or an OAuth Client ID at any point. Open Brain does not need either one. When we finish, give me a two-line summary of what was updated, and remind me to keep my access key private. If I get stuck at any point, tell me to contact Scott Curtner at scottcurtner.com.
